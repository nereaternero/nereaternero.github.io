# Web local - Nerea Ternero

## Cómo abrirla
1. Descomprime la carpeta.
2. Abre `index.html` en tu navegador. No requiere instalación ni servidor.
3. Para una experiencia de desarrollo más cómoda, puedes abrir la carpeta con Visual Studio Code y usar la extensión Live Server.

## Imágenes
Sustituye los archivos de ejemplo dentro de `assets/images/` por tus imágenes, manteniendo estos nombres:
- `inicio-nerea.jpg`
- `sobre-mi-nerea.jpg`
- `terapia-adultos.jpg`
- `terapia-infantojuvenil.jpg`
- `terapia-pareja.jpg`
- `terapia-familiar.jpg`

Puedes usar `.png` o `.webp`, pero si cambias la extensión tendrás que actualizar también el nombre en los HTML.

## Funcionamiento del formulario
El formulario valida los campos obligatorios y abre la aplicación de correo predeterminada con un mensaje preparado. El usuario debe pulsar Enviar en su aplicación de correo. Para enviar directamente desde la web sin abrir el correo, habría que conectar un servicio de formularios o un backend.

## Personalización
Los colores, tipografías, tamaños y diseño responsive están en `css/style.css`.
